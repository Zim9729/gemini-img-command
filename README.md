# Gemini 图片生成命令（/img）— 油猴脚本

在 [gemini.google.com](https://gemini.google.com/) 用**一条命令**完成图片生成全流程：

> **选图 → 自动上传 → 发送提示词 → 等待生成完成 → 按原图文件名下载**

以命令的形式存在，不占用页面界面：在 Gemini 输入框输入 `/img 把画面改成下雪的冬天` 并回车，弹出选图框选好图之后，剩下的事情全部自动完成。

---

## ✨ 功能特性

- **命令式触发**：`/img` 输入框命令、`Alt+G` 快捷键、Tampermonkey 菜单命令，三种入口
- **多图排队**：一次选多张图，逐张自动处理
- **自动新开对话**：每张图在独立的新对话中处理，互不污染上下文（可关闭）
- **按原图命名**：生成图严格使用上传图片的文件名（`ABC_001.jpg` → `ABC_001.jpg`）
- **断点续跑**：队列存入浏览器（localStorage + IndexedDB），中途刷新/关页面后重新打开自动继续
- **状态面板**：右下角可拖动面板实时显示每张图的处理进度和日志
- **诊断工具**：`/imgdiag` 一键检查页面元素，Google 改版后快速定位问题

## 📦 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（篡改猴）扩展（Chrome / Edge 均可）
2. 点击 Tampermonkey 图标 → 「添加新脚本」→ 删除默认内容 → 粘贴 `gemini-img-command.user.js` 的全部内容 → `Ctrl+S` 保存
   - 或者：把 `gemini-img-command.user.js` 文件直接拖入浏览器，在 Tampermonkey 安装页点「安装」
3. 打开 <https://gemini.google.com/> 并登录你的 Google 账号
4. **在 Gemini 的模型选择器中选择支持图像生成的模型**（如「图像生成」/ Nano Banana / Gemini 2.5 Flash Image），并先手动确认你能在网页版生成图片

## 🚀 使用

### 方式一：命令（推荐）

在 Gemini 输入框输入：

```
/img 把画面改成下雪的冬天
```

回车 → 弹出文件选择框（可多选）→ 之后全自动：上传 → 发送 → 等待 → 下载。

### 方式二：快捷键

按 `Alt+G` → 弹出选图框 → 使用默认提示词（先用 `/imgset` 保存）。

### 方式三：油猴菜单

点击浏览器工具栏 Tampermonkey 图标 → 「🖼 选图并执行（默认提示词）」。

## 📜 命令列表

| 命令 | 作用 |
| --- | --- |
| `/img <提示词>` | 选图并执行；提示词省略时使用默认提示词 |
| `/imgset <提示词>` | 设置默认提示词 |
| `/imgconf` | 切换「每张图新开对话」（默认开） |
| `/imgname` | 切换「严格原名 / 自动纠正扩展名」（默认严格原名） |
| `/imgclear` | 停止并清除当前队列 |
| `/imgdiag` | 诊断页面元素（排查选择器失效） |
| `/imghelp` | 显示帮助 |

## 🏷️ 命名规则

- 默认**严格使用原文件名**：上传 `中心锚结-01.jpg` → 下载 `中心锚结-01.jpg`
- 一次生成多张图时：`中心锚结-01.jpg`、`中心锚结-01_2.jpg`、`中心锚结-01_3.jpg` ……
- 若生成图实际格式与扩展名不符（如 PNG 数据存成 `.jpg`），默认仍保留原名；用 `/imgname` 可切换为「自动纠正扩展名」

## ⚠️ 注意事项

1. **下载位置**：文件保存到浏览器「下载」文件夹（可在浏览器设置中修改默认下载路径）。连续下载多个文件时，浏览器首次会询问「允许下载多个文件」，请点击**允许**。
2. **图像生成模型**：脚本不改变 Gemini 的行为，只是自动化操作。当前选择的模型必须支持图像生成，否则回复是纯文字，脚本会报「回复中没有生成图片」。
3. **额度限制**：免费账号的图像生成有次数限制，超限时同样会失败，脚本会跳过该图继续处理下一张。
4. **Google 改版风险**：脚本依赖 Gemini 页面的 DOM 结构（多层选择器 + 多种兜底）。如果哪天全部失效，在输入框输入 `/imgdiag`，把弹出的诊断结果反馈给维护者即可快速修复。
5. **多标签页安全**：同一时间只有一个标签页执行队列，其余标签页不会重复处理。
6. **隐私**：脚本只在你的浏览器本地运行，不向任何第三方发送数据；图片仅上传到 Gemini 本身。

## 🔧 工作原理

```
/img 命令（输入框回车 / Alt+G / 油猴菜单）
   │
   ├─ 弹出文件选择框（可多选）→ 队列写入 localStorage + IndexedDB（支持断点续跑）
   │
   └─ 逐张处理：
        ① 新开对话（点击侧栏按钮；找不到则跳转 /app 后自动续跑）
        ② 上传图片（填充页面 file input → 失败则模拟粘贴进输入框）
        ③ 填入提示词（Quill 编辑器 execCommand）
        ④ 点击发送，轮询「停止按钮消失 + 发送按钮恢复」判断生成完成
        ⑤ 抓取回复中的生成图（排除用户消息原图 / 输入框预览）
        ⑥ fetch / GM_xmlhttpRequest 取回图片数据，按原图文件名触发下载
```

## ❓ 常见问题

**Q：为什么提示「回复中没有生成图片」？**
A：模型没出图。常见原因：当前模型不支持图像生成、触发了安全策略、达到免费额度。先手动在网页上试一次同样的操作确认能出图。

**Q：为什么提示「找不到发送按钮 / 无法把图片放入输入框」？**
A：Google 改版导致选择器失效。运行 `/imgdiag` 把结果反馈给维护者。

**Q：中途关掉了页面怎么办？**
A：重新打开 gemini.google.com，脚本检测到未完成的队列会自动续跑（剩余图片仍在）。

**Q：能一次处理整个文件夹吗？**
A：选图时按 `Ctrl+A` 全选文件夹内的图片即可排队处理。

**Q：支持哪些浏览器？**
A：所有能运行 Tampermonkey 的 Chromium 系浏览器（Chrome / Edge）。Firefox + Tampermonkey 也应可用，未充分测试。
