# Gemini 批量图片生成面板 — 油猴脚本

在 [gemini.google.com](https://gemini.google.com/) 上批量生成/编辑图片的**配置面板**：

> 提前在面板里选好**文件夹**、填好**提示词** → 点击 **「▶ 执行」** → 自动循环文件夹里的每一张图
> （每张图一个独立新对话：上传 → 发送 → 等待生成 → 按原图文件名下载），直至全部完成。

以**配置界面**形式使用，无聊天命令，不需要往对话框输入任何指令。

---

## ✨ 功能特性

- **配置面板**：右下角 🖼 悬浮按钮（或 `Alt+G`）打开；文件夹、提示词、选项全部在面板内预先设置
- **整文件夹批量**：选中文件夹后自动递归收集所有图片（含子文件夹，忽略非图片文件），并**记住该文件夹**，下次点「执行」直接用
- **提示词自动保存**：填一次，之后每次打开都在
- **全自动循环**：每张图单独开一个新对话（可关）→ 上传 → 发送 → 等待生成完成 → 下载，失败自动跳过继续下一张
- **按原图命名**：生成图严格使用上传图片的文件名（`ABC_001.jpg` → `ABC_001.jpg`）
- **断点续跑**：队列存入浏览器（localStorage + IndexedDB），中途刷新/关页面后重新打开自动继续
- **多标签页安全**：同一时间只有一个标签页执行队列
- **实时进度**：面板内逐图显示 ⏳/✅/❌ 和运行日志
- **诊断工具**：「🔍 诊断」一键检查页面元素，Google 改版后快速定位问题

## 📦 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（篡改猴）扩展（Chrome / Edge 均可）
2. Tampermonkey 图标 → 「添加新脚本」→ 删除默认内容 → 粘贴 `gemini-img-command.user.js` 的全部内容 → `Ctrl+S` 保存
   - 或者：把 `gemini-img-command.user.js` 文件直接拖入浏览器，在弹出的安装页点「安装」
3. 打开 <https://gemini.google.com/> 并登录你的 Google 账号
4. **在 Gemini 的模型选择器中选择支持图像生成的模型**（如「图像生成」/ Nano Banana / Gemini 2.5 Flash Image），并先手动确认你能在网页版生成图片

> 更新脚本：Tampermonkey 管理面板 → 打开本脚本 → 全选替换为新版全文 → `Ctrl+S`。

## 🚀 使用

1. **打开面板**：点击右下角 🖼 圆形按钮（或按 `Alt+G`）。首次安装会自动弹出
2. **选择文件夹**：点「📁 选择文件夹…」→ 在系统弹窗中选中存放待生成图片的文件夹 → 面板显示「文件夹名 · N 张图片」
   - 文件夹会被**记住**：下次直接点「▶ 执行」即可（浏览器可能弹一次重新授权，点允许）
3. **填写提示词**：在「提示词」输入框填入对所有图片生效的提示词（自动保存）
4. **点击「▶ 执行」**：开始全自动循环，面板实时显示每张图进度：
   ```
   【⏳】1. 中心锚结-01.jpg   ← 正在处理
   【✅】2. 中心锚结-02.jpg   ← 已下载（文件名与原图相同）
   【❌】3. 中心锚结-03.jpg   ← 失败原因（已跳过）
   ```
5. 全部完成后提示「成功 X，失败 Y」；中途可点「⏹ 停止」终止（已完成的图片不受影响）

> 受浏览器安全限制，**不能直接输入本地路径文本**（如 `E:\photos`），文件夹必须通过系统选择框指定一次；指定后脚本持久化记住，效果等同于提前配置好路径。

## 🏷️ 命名规则

- 默认**严格使用原文件名**：上传 `中心锚结-01.jpg` → 下载 `中心锚结-01.jpg`
- 一次生成多张图时：`中心锚结-01.jpg`、`中心锚结-01_2.jpg`、`中心锚结-01_3.jpg` ……
- 若生成图实际格式与扩展名不符（如 PNG 数据存成 `.jpg`），默认仍保留原名；取消勾选「严格原文件名」可切换为自动纠正扩展名

## ⚠️ 注意事项

1. **下载位置**：文件保存到浏览器「下载」文件夹（可在浏览器设置中修改默认下载路径）。连续下载多个文件时，浏览器首次会询问「允许下载多个文件」，请点击**允许**。
2. **图像生成模型**：当前选择的模型必须支持图像生成，否则回复是纯文字，日志会报「回复中没有生成图片」。
3. **额度限制**：免费账号的图像生成有次数限制，超限时该图失败并自动跳过。
4. **每图新开对话**：默认开启。关闭后所有图在同一对话内连续发送（可能互相影响上下文）。
5. **Google 改版风险**：脚本依赖 Gemini 页面的 DOM 结构（多层选择器 + 多种兜底）。如果哪天全部失效，点面板里的「🔍 诊断」，把弹出的结果反馈给维护者即可快速修复。
6. **隐私**：脚本只在你的浏览器本地运行，不向任何第三方发送数据；图片仅上传到 Gemini 本身。

## 🔧 工作原理

```
配置面板（选文件夹 + 填提示词 + 执行）
   │
   ├─ 文件夹选择三层兜底：原生 showDirectoryPicker → input[webkitdirectory] → 页面内按钮
   ├─ 文件夹句柄存入 IndexedDB（记住上次文件夹）；图片队列同样持久化（断点续跑）
   │
   └─ 点击「执行」→ 逐张循环：
        ① 新开对话（点击侧栏按钮；找不到则跳转 /app 后自动续跑）
        ② 上传图片（填充页面 file input → 失败则模拟粘贴进输入框）
        ③ 填入提示词（Quill 编辑器 execCommand）
        ④ 点击发送，轮询「停止按钮消失 + 发送按钮恢复」判断生成完成
        ⑤ 抓取回复中的生成图（排除用户消息原图 / 输入框预览）
        ⑥ fetch / GM_xmlhttpRequest 取回图片数据，按原图文件名触发下载
```

## ❓ 常见问题

**Q：为什么提示「回复中没有生成图片」？**
A：模型没出图。常见原因：当前模型不支持图像生成、触发了安全策略、达到免费额度。先手动在网页上试一次同样的操作确认能出图。

**Q：点「选择文件夹」没反应？**
A：脚本版本需 ≥ 1.2.0（v2.0.0 为面板模式）。v2.0.0 的选择框在用户手势内直接打开；若浏览器仍拦截，会弹出页面内按钮，点它即可。若还不行，点「🔍 诊断」把结果反馈给维护者。

**Q：中途关掉了页面怎么办？**
A：重新打开 gemini.google.com，面板自动弹出并续跑剩余图片（右下角 🖼 可重新打开面板）。

**Q：能直接填 E:\xxx 这样的路径吗？**
A：不能，这是浏览器的安全限制（网页脚本不能随意读本地磁盘）。替代方案就是「选择一次文件夹并被记住」，点「执行」时如浏览器询问权限，点允许即可。

**Q：支持哪些浏览器？**
A：所有能运行 Tampermonkey 的 Chromium 系浏览器（Chrome / Edge，推荐）。Firefox 部分功能（记住文件夹句柄）不可用，但基本流程可用。
